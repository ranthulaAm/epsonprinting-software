# Print Helper — Spoken-Style Sinhala Localization Glossary

This glossary defines standard, consistent spoken-style Sinhala translations for all technical and user-interface terms used throughout the Print Helper application.

## Core Rules for Sinhala UI
1. **Spoken, Everyday Language**: Use terms that an ordinary Sri Lankan shop owner, student, or elderly citizen uses in daily conversation.
2. **Loanwords in Sinhala Script**: Where Sri Lankans normally use the English word in daily life, keep it in Sinhala phonetics (`ප්‍රින්ටර්`, `ෆයිල්`, `PDF`, `ඉන්ක්`, `ස්කෑන්`). Never invent artificial textbook terms (e.g. avoid `මුද්‍රණ යන්ත්‍රය`, `ලේඛන`).
3. **Consistency**: Always use the same word for the same concept across the entire application (e.g. always `කඩදාසි` for paper, never alternating with `පත්ති` or `පත්‍රිකා`).
4. **Short & Action-Oriented**: Buttons are 1–2 words (e.g. `ප්‍රින්ට් කරන්න`, `සුරකින්න`, `අයින් කරන්න`).
5. **Clear Error Explanations**: First state what happened in plain terms, then tell the user what action to take.
6. **Standard Digits**: All numbers, copy counts, and page numbers remain in standard digits (1, 2, 3...).
